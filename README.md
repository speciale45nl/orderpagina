# Orderpagina Spéciale45

Werkplaats-checklist per auto voor 1stop, de interieurspecialist en Spéciale45. Inloggen met rol + 4-cijferige pincode.

- `docs/` – de pagina (gehost via GitHub Pages). Data en foto's staan in Firebase (project speciale45-orders).
- `firestore.rules` – beveiligingsregels van de database.

Deze repository bevat geen klantgegevens.
